changes = []
for package, wanted in REQUIRED_VERSIONS.items():
    try:
        installed = importlib.metadata.version(package)
    except importlib.metadata.PackageNotFoundError:
        installed = None
    if installed != wanted:
        changes.append(f'{package}=={wanted}')

Phase 2 - Understand, validate, and prepare the dataset¶

The Cleveland dataset contains 303 records. Use exactly four raw inputs:

  • cp: chest pain category (1 typical angina; 2 atypical angina; 3 non-anginal; 4 asymptomatic).
  • thalach: maximum exercise heart rate, in beats per minute.
  • oldpeak: exercise-induced ST depression relative to rest.
  • thal: thallium test result (3 normal; 6 fixed defect; 7 reversible defect).

Convert num = 0 to absence (0), and num = 1-4 to presence (1). Replace '?' with missing values. Imputation is fitted later inside training folds. This is an educational classifier of recorded disease status, not future risk.

Phase 4 - Build the preprocessing pipeline¶

Encode categorical inputs using source-defined category vocabularies. Impute categorical missing values with the training-fold mode. Numeric inputs, when present, use median imputation and standard scaling inside the same fold. One-hot columns represent original inputs; they do not add new raw attributes.

In [6]:
transformers = []
if NUMERIC:
    numeric_pipeline = Pipeline([('imputer', SimpleImputer(strategy='median')),
                                 ('scaler', StandardScaler())])
    transformers.append(('numeric', numeric_pipeline, NUMERIC))
categorical_pipeline = Pipeline([
    ('imputer', SimpleImputer(strategy='most_frequent')),
    ('encoder', OneHotEncoder(categories=CATEGORIES, handle_unknown='ignore', sparse_output=False))])
transformers.append(('categorical', categorical_pipeline, CATEGORICAL))
preprocessor = ColumnTransformer(transformers, remainder='drop')

Phase 5 - Train and compare candidate models using cross-validation¶

Compare a majority-class baseline, SVC, Logistic Regression, and Random Forest. Report average training accuracy and validation accuracy across the same five folds. Training accuracy here is the mean across CV training folds, not a separate score measured on the complete development partition.

Phase 6 - Tune hyperparameters and freeze the selected model¶

Reproduce the predefined version-1 search: tune SVC; tune the other families when baseline accuracy is within 0.05 of the best non-dummy baseline. Selection uses CV accuracy, then F1, then model name for ties. The reserved test set is not used for this selection. These are tuning-CV scores; broader future feature searches should use nested CV for evaluation of the search.
