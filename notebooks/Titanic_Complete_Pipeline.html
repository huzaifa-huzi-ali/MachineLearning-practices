Phase 4 - Build the preprocessing pipeline¶

Encode categorical inputs using source-defined category vocabularies. Impute categorical missing values with the training-fold mode. Numeric inputs, when present, use median imputation and standard scaling inside the same fold. One-hot columns represent original inputs; they do not add new raw attributes.

In [6]:
transformers = []
if NUMERIC:
    numeric_pipeline = Pipeline([('imputer', SimpleImputer(strategy='median')),
                                 ('scaler', StandardScaler())])
    transformers.append(('numeric', numeric_pipeline, NUMERIC))
categorical_pipeline = Pipeline([
    ('imputer', SimpleImputer(strategy='most_frequent')),
    ('encoder', OneHotEncoder(categories=CATEGORIES, handle_unknown='ignore', sparse_output=False))])
transformers.append(('categorical', categorical_pipeline, CATEGORICAL))
preprocessor = ColumnTransformer(transformers, remainder='drop')

Phase 6 - Tune hyperparameters and freeze the selected model¶

Reproduce the predefined version-1 search: tune SVC; tune the other families when baseline accuracy is within 0.05 of the best non-dummy baseline. Selection uses CV accuracy, then F1, then model name for ties. The reserved test set is not used for this selection. These are tuning-CV scores; broader future feature searches should use nested CV for evaluation of the search.
